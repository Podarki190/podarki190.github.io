## Сделано

**Домен и продвижение.** `lazerklin.ru` зарегистрирован в Бегете (до 18.08.2027),
DNS на GitHub Pages, HTTPS работает. Права подтверждены в Яндекс.Вебмастере
(файл `yandex_647c4b8adf060779.html`) и в Google Search Console (доменный ресурс,
TXT-запись). Карты сайта отправлены в оба. Регион «Клин» подан. Метрика 111720390
стоит на всех страницах, в политике конфиденциальности описана. Старый сайт в
репозитории `wall-clocks-catalog` погашен, его workflow удалён.

**Каталог.** Тянется из WB Content API: часы (раздел 625) и кружки (7476).
Часы сверху, кружки в самом низу. Цены: часы 1890 ₽ (зачёркнуто 7000),
двухслойные `.jiv` 2690 ₽, кружки 749 ₽ (зачёркнуто 1500). Адреса страниц —
из названия латиницей: `/tovar/chasy-nastennye-mishki-pandy/`; тёзкам
дописывается номер WB. Старые числовые ссылки живы: их ловит `404.html`.

**Поиск** идёт по всему каталогу, а не по видимым карточкам: `catalog.json`
качается при вводе двух букв, результаты показываются плитками с фото и ценой.

**Услуги.** 156 страниц, у каждой свой поисковый запрос и свой текст.
Общие страницы («Гравировка», «Печати и штампы», «Медальницы», «Трафареты»,
«Плоттерная резка») работают оглавлениями и ссылаются на узкие.

**Заявки.** На странице товара — форма заказа, на страницах услуг — форма
«Есть вопрос или нужен расчёт?». Обе шлют заявку в Telegram и в гугл-таблицу
через Apps Script; при обрыве связи предлагают мессенджер.

**Блог РАБОТАЕТ (24.08.2026).** https://lazerklin.ru/blog/ — раздел живой, в меню,
в карте сайта. Одна статья на сайте раздаётся сразу на четыре площадки.

```
наш workflow ──→ lazerklin.ru      статья, 3 фото
             ├─→ Telegram          3 фото + текст
             │      └─→ Дзен       статья с фото (сам)
             │            └─→ ОК   статья с фото (сам)
             └─→ ВКонтакте         текст + ссылка
```

Пять площадок, ноль рублей в месяц. Платный планировщик не нужен.

**Одноклассники достались даром:** Дзен сам завёл там группу «Лазер Клин —
гравировка и резка» и публикует в неё статьи с фотографиями. Аккаунт в ОК
владельцу не нужен — только если захочет отвечать на комментарии.

**ВК — ТОЛЬКО ТЕКСТ, и это потолок, а не лень.** Фотографию на стену групповым
ключом не положить ни одним способом: штатные методы закрыты (ошибка 27), фото
через сервер сообщений `wall.post` принимает без ошибки, но стена его молча
выбрасывает — и с `access_key` тоже. Ссылка вложением даёт
«link_photo_sizing_rule. No photo given» на ЛЮБОЙ ссылке, хоть на Хабре.
Работает единственное — ссылка внутри текста, карточку ВК на неё не рисует.
Поэтому в конец поста добавляется строка «Фотографии этой работы, размеры и
сроки — на сайте:» — иначе голая ссылка выглядит обрубком.

Токен пользователя снял бы ограничения, но у приложения типа «Мини-приложение»
(единственный, который ВК сейчас даёт) нет права `offline`: токен пришлось бы
обновлять каждый запуск и хранить обновлённый, то есть завести ключ с правом
переписывать секреты репозитория. Решено не делать. Таблица проверенных методов —
в памяти, `vk-autopost-api`.

ВАЖНО ПРО ТЕКСТЫ ДЛЯ ВК: раз картинки нет, пост обязан НАЧИНАТЬСЯ с самой вещи
(«Сделали табличку…»), а не с захода издалека. Статья и версия для Telegram
начинаются иначе — там фотографии есть.

**Telegram.** Канал `t.me/lazerklin_ru`, публичный. Админы: владелец и `zen_sync_bot`.
Значок Telegram в подвале сайта ведёт на канал, а личка `@Podarki190` осталась
на «Контактах» и в кнопках заказа: в личку пишут заказ, на канал подписываются.

**Дзен.** Канал «Лазер Клин — гравировка и резка», сайт подтверждён файлом
`static/zen_Jszj4...html`. RSS-импорт Дзен даёт только с 10 подписчиков, поэтому
идём через кросспостинг из Telegram — он без ограничений.

**Фотоархив блога** — `Desktop\Для сайта ИИ`: настоящие фото работ, разложенные
по изделиям. 211 групп по имени, из них 118 с тремя и более кадрами. Внутри групп
попадаются РАЗНЫЕ изделия (в «Медальница именная спорт» их семь), так что реальных
тем больше. Папка «Чужие макеты» — работы друзей и коллег, публиковать можно, но
подписывать «делаем такое же на заказ», а не «наша работа».

**Как устроен блог.** `src/blog.js` — один массив `POSTS`, запись = одна работа:
три фотографии, статья на сайт, текст для ВК и текст для Telegram лежат вместе.
Разносить их по разным файлам нельзя: однажды опубликуется текст от одной работы
с фотографиями от другой. Публикуется то, у чего дата не в будущем **по Москве**,
а не по UTC. Значит пачка постов пишется на месяц вперёд и выходит сама.

Написано 9 постов до 16 сентября: табличка «Перерыв до», медальницы (гимнастка,
каратист, баскетболист, волейболистка), часы Санкт-Петербург, часы Шестерёнки,
подставки под телефон партией, фигура «Семья медведей».

`scripts/publish.mjs` — раздача поста дня. Прогон вхолостую: `node scripts/publish.mjs --dry-run`.
Что уже отправлено, лежит в `publish-state.json` и коммитится обратно; без этого
повторный запуск продублировал бы пост, а в ВК это необратимо.

**РУБИЛЬНИК ПУБЛИКАЦИИ ВЫКЛЮЧЕН.** Workflow `publish.yml` ничего не делает, пока в
Settings → Secrets and variables → Actions → Variables не заведена переменная
`PUBLISH_ENABLED = true`. Расписание при этом уже стоит: 07:00 UTC, то есть 10:00
по Москве, через четыре часа после ночной сборки сайта — чтобы ссылка из поста
вела на уже существующую статью.

**ЗАЩИТА ОТ ЧУЖИХ ПРАВ.** В `test/blog.test.js` есть список маркеров: группы,
автомарки, спортклубы, кино. Тест падает, если такое слово попало в пост. Повод
конкретный: был написан пост про часы с Цоем без сверки с аудитом каталога, а
музыкальная тематика там тир B, «снимать». Блог о таком товаре хуже самого
товара: это реклама спорного изделия на своём домене, с телефоном, навсегда в
индексе. Пост удалён, ключница «Король и Шут» по той же причине не писалась.
Список неполон по определению — он нужен, чтобы вопрос вообще был задан.

**ВИДЕО-КОНВЕЙЕР (24.08.2026).** Три скрипта в `scripts/`:

- `video-inbox.mjs` — забирает ролики, присланные боту в личку. Отправлять надо
  ОБЫЧНЫМ ВИДЕО, не «как файл»: Bot API отдаёт скачивание только до 20 МБ, а при
  обычной отправке телефон сам сжимает до приемлемого.
- `video-prep.mjs` — обрезка, музыка, громкость до −14 LUFS, затемнение в конце,
  сжатие. Вертикальный кадр НЕ растягивается до 1080: телефон отдал 720×1280,
  апскейл добавит только вес. Стабилизация за флагом `--stab`, по умолчанию нет.
- `video-send.mjs` — отправка в канал; дальше Дзен и ОК подхватывают сами.
  ВКонтакте в цепочке нет: `video.save` закрыт групповому ключу так же, как фото.

ffmpeg 9.0 поставлен через winget, но в PATH появляется только в новой консоли.
Лежит в `AppData\Local\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-*-full_build\bin`.

**Музыка для роликов** — `Рабочий стол\Музыка для роликов`, 15 треков с Mixkit,
лицензия разрешает коммерческое использование без указания автора. Там же файл
«ПРОЧТИ — про лицензии.txt». В папке `Music` у владельца лежат Iggy Pop, RHCP и
Elvis с сайтов минусовок — их использовать НЕЛЬЗЯ ни в роликах, ни где-либо ещё.

## Грабли, на которые уже наступали

- Работа идёт в worktree на ветке `worktree-wall-clocks-catalog-build`.
  Пушить только так: `git push origin worktree-wall-clocks-catalog-build:main`.
  `git push origin master` молча отвечает «Everything up-to-date».
- Пуш с мегабайтами картинок отваливается по таймауту (HTTP 408) —
  помогает `git config http.postBuffer 524288000` и повтор.
- `CNAME` с доменом кладёт сама сборка: GitHub при публикации своим workflow
  этот файл не создаёт, и без него домен слетает на github.io.
- Nano Banana коверкает кириллицу и на слово «плоттер» рисует лазерный станок.
  В промтах писать «настольный режущий плоттер с рулоном плёнки, без лазера».
- Фото услуг ужимать до 1400 px по ширине, quality 80: оригиналы по 3 МБ
  на сайт класть нельзя.
- Фото работ НЕ улучшать нейросетью: на изделиях гравированный текст, любая
  перерисовка превратит его в кракозябры. Только тон и размер, содержимое не трогать.
- ImageMagick не установлен, а `convert` в PATH — это ВИНДОВЫЙ дисковый `convert.exe`.
  Обрабатывать через Pillow (стоит 12.3), не через `convert`.
- Веб-версия Telegram не умеет добавлять ботов в администраторы канала: её поиск
  ищет только среди подписчиков. Делать в десктопном приложении или с телефона.
- В ВК `wall.delete` и `wall.edit` групповому ключу НЕДОСТУПНЫ: созданный через API
  пост удаляется только руками из «Отложенных записей». Тестировать с оглядкой.
- Первое предложение поста в Telegram становится заголовком статьи в Дзене (140
  знаков), первое фото — обложкой. Писать первую строку как заголовок.
- В репозитории иногда работает вторая сессия. Перед началом — `git status`
  и `git log origin/main`.
