# Фотографии наших работ

Всё, что лежит в этой папке с расширением `.jpg`, `.jpeg`, `.png` или `.webp`,
попадает на страницу сайта **«Фото работ»** (`/foto-rabot/`) — сама, без правок
кода. Папка пуста — страницы нет ни в меню, ни в карте сайта.

## Как называть файлы

Имя файла становится подписью под фотографией и текстом `alt` для поисковика,
поэтому называть надо по-человечески и по-русски:

    Медальница для гимнастки.jpg
    Часы из виниловой пластинки.jpg

Порядок на странице — по алфавиту. Чтобы задать свой, поставьте номер впереди
(в подпись он не попадёт):

    01 Часы с гравировкой на юбилей.jpg
    02 Кубок для турнира по самбо.jpg

## Размер

Перед укладкой фотографию нужно ужать: ширина 1400 px, качество 80 — это
150–250 КБ на снимок. Оригиналы с телефона по 3–5 МБ класть сюда нельзя,
страница будет открываться минуту.
